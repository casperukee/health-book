# 术语表

本表用于保持中英文术语一致。英文版启动前逐步补齐。

| 中文 | English | 说明 |
|---|---|---|
| 健康判断力 | health decision literacy | 项目核心能力 |
| 健康寿命 | healthspan | 重点是功能和生活质量 |
| 功能能力 | functional ability | 健康老龄化中的核心概念，强调能做什么 |
| 内在能力 | intrinsic capacity | 个体可调用的身体和心理能力 |
| 风险曲线 | risk curve | 风险随时间和背景逐渐变化的理解方式 |
| 风险语言 | risk language | 用来解释体检指标和长期风险 |
| 危险信号 | red flags | 需要及时就医或急救的信号 |
| 体检指标 | checkup markers | 体检、化验和测量项目中的风险信号 |
| 参考范围 | reference range | 帮助解释检测结果的参照范围，不等于绝对诊断线 |
| 趋势 | trend | 同一指标随时间的变化方向 |
| 组合风险 | combined risk | 多个指标、病史和生活背景叠加后的风险 |
| 代谢健康 | metabolic health | 能量、脂质、血压、尿酸和体重等系统状态 |
| 四高 | four highs | 血压、血脂、血糖、尿酸四类常见风险指标 |
| 心肾代谢风险 | cardio-kidney-metabolic risk | 心血管、肾脏和代谢系统交织的长期风险 |
| 动脉粥样硬化 | atherosclerosis | 动脉内斑块逐渐形成并影响血流的过程 |
| 心血管事件链 | cardiovascular event chain | 从风险因素到血管变化、急性事件和防复发的链条 |
| 保健品 | dietary supplements | 用于补充饮食的产品，不等同于药品 |
| 草药补剂 | herbal supplements | 含草药或植物成分的补剂 |
| 产品一致性 | product consistency | 市售产品与研究材料在成分、剂量、纯度上的一致程度 |
| 就医资料包 | visit prep packet | 就医前准备的症状、资料、用药和问题清单 |
| 家庭健康档案 | family health record | 家庭可维护的病史、用药、检查和联系人记录 |
| 家庭健康操作系统 | family health operating system | 家庭资料、流程、分工和复盘 |
| 证据边界 | evidence boundary | 某个判断能说到哪里、不能说到哪里 |
