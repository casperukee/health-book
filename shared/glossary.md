# 术语表

本表用于保持中英文术语一致。英文版启动前逐步补齐。

| 中文 | English | 说明 |
|---|---|---|
| 健康有谱 | health decision literacy | 项目名；核心含义是把健康问题理出章法 |
| 健康寿命 | healthspan | 重点是功能和生活质量 |
| 功能能力 | functional ability | 健康老龄化中的核心概念，强调能做什么 |
| 内在能力 | intrinsic capacity | 个体可调用的身体和心理能力 |
| 风险曲线 | risk curve | 风险随时间和背景逐渐变化的理解方式 |
| 风险语言 | risk language | 用来解释体检指标和长期风险 |
| 危险信号 | red flags | 需要及时就医或急救的信号 |
| 体检指标 | checkup markers | 体检、化验和测量项目中的风险信号 |
| 参考范围 | reference range | 帮助解释检测结果的参照范围，不等于绝对诊断线 |
| 趋势 | trend | 同一指标随时间的变化方向 |
| 组合风险 | combined risk | 多个指标、病史和生活背景叠加后的风险 |
| 代谢健康 | metabolic health | 能量、脂质、血压、尿酸和体重等系统状态 |
| 四高 | four highs | 血压、血脂、血糖、尿酸四类常见风险指标 |
| 心肾代谢风险 | cardio-kidney-metabolic risk | 心血管、肾脏和代谢系统交织的长期风险 |
| 动脉粥样硬化 | atherosclerosis | 动脉内斑块逐渐形成并影响血流的过程 |
| 心血管事件链 | cardiovascular event chain | 从风险因素到血管变化、急性事件和防复发的链条 |
| 睡眠动力 | sleep pressure | 清醒时间、活动和睡眠债推动入睡的生理倾向 |
| 昼夜节律 | circadian rhythm | 身体内部的时间节律，受光照、起床、进食和活动影响 |
| 身体阻力 | somatic resistance | 疼痛、肌肉紧张、身体高张力或不适对睡眠和恢复形成的阻力 |
| 日间功能 | daytime functioning | 白天清醒、注意、情绪、工作学习和安全表现 |
| 非睡眠深度休息 | non-sleep deep rest (NSDR) | 用于短时降低高唤醒和恢复注意力的休息练习，不替代夜间睡眠 |
| 失眠认知行为治疗 | cognitive behavioral therapy for insomnia (CBT-I) | 针对失眠的结构化治疗路径，不等同于普通睡眠技巧 |
| 认知健康 | cognitive health | 记忆、学习、判断、语言、注意和执行功能等状态 |
| 痴呆 | dementia | 影响日常功能的认知和行为综合征，不等同于正常衰老 |
| 心理危机 | mental health crisis | 自伤、自杀、严重失控或无法保证安全的心理健康急迫状态 |
| 癌症筛查 | cancer screening | 在无症状人群中寻找早期癌症或癌前病变的检查 |
| 过度诊断 | overdiagnosis | 发现原本可能不会造成症状或死亡的问题，并可能引发后续伤害 |
| 慢病指标记录 | chronic marker log | 用于追踪血压、血糖、血脂、尿酸等长期指标趋势的家庭记录 |
| 专科就医地图 | specialty care map | 遇到具体专科问题时判断急缓、入口、资料和下一步的框架 |
| 健康默认值 | health defaults | 家庭中让健康行为更容易发生的环境、流程和习惯默认设置 |
| 健康触发器 | health triggers | 需要记录、复查、就医或急救的预设行动条件 |
| 照护分工 | care coordination | 家庭在资料、陪诊、复查、费用、交通和日常照护中的协作安排 |
| 日常生活能力 | activities of daily living | 吃饭、穿衣、洗澡、如厕、起身和走动等基本生活能力 |
| 工具性生活能力 | instrumental activities of daily living | 做饭、购物、用药、用钱、交通和家务等较复杂生活能力 |
| 用药安全 | medication safety | 关注药物、剂量、相互作用、漏服、重复用药和不良反应的安全管理 |
| 跌倒风险 | fall risk | 老年人跌倒或差点跌倒的可能性及相关环境、功能和药物因素 |
| 照护者负担 | caregiver burden | 长期照护带来的体力、情绪、时间和经济压力 |
| 家用健康设备 | home health devices | 在家庭环境中用于测量、提醒或辅助管理健康的设备 |
| 直接面向消费者的检测 | direct-to-consumer tests | 不经医生直接向消费者销售的检测服务 |
| 分析准确性 | analytical validity | 检测是否可靠测到声称测量对象 |
| 临床相关性 | clinical validity | 检测结果是否与某个健康状态或风险有可靠关系 |
| 替代终点 | surrogate endpoint | 用于间接代表健康结果的指标，不能自动等于真实获益 |
| 健康欺诈 | health fraud | 用未证实安全有效的产品宣称预防、治疗或治愈疾病 |
| 健康信息评估 | evaluating health information | 判断健康信息来源、证据、适用性和行动风险的过程 |
| 保健品 | dietary supplements | 用于补充饮食的产品，不等同于药品 |
| 草药补剂 | herbal supplements | 含草药或植物成分的补剂 |
| 产品一致性 | product consistency | 市售产品与研究材料在成分、剂量、纯度上的一致程度 |
| 就医资料包 | visit prep packet | 就医前准备的症状、资料、用药和问题清单 |
| 家庭健康档案 | family health record | 家庭可维护的病史、用药、检查和联系人记录 |
| 家庭健康操作系统 | family health operating system | 家庭资料、流程、分工和复盘 |
| 证据边界 | evidence boundary | 某个判断能说到哪里、不能说到哪里 |
