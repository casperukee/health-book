# 健康有谱

给家庭的长期健康读本。

这个项目帮助普通读者把健康问题理出章法：理解风险、准备就医、管理家庭健康信息、识别健康消费陷阱。

它不是医疗建议，不替代医生诊断、治疗、用药、停药、筛查或急救判断。出现胸痛、晕厥、卒中症状、严重疼痛、异常出血、呼吸困难、自伤或自杀风险等危险信号时，请及时就医或联系当地急救服务。

## 这个项目帮助你

- 把健康问题分成可理解的风险类别；
- 知道什么时候该记录、观察、复查或就医；
- 更好地准备医生沟通；
- 建立家庭健康资料和行动模板；
- 识别保健品、抗衰、健康设备中的常见证据陷阱。

## 当前状态

当前版本为 v0.9：主书已经从“工具箱”进一步升级为“给全家健康守门人的判断指南”，本轮重点统一了正文内容、医学边界和网页版阅读体验，并继续强化症状分流、体检/筛查边界、就医准备、家庭协作和健康信息防御。

当前版本可以连续阅读，也可以按场景查工具页；但它仍不是医疗建议，也尚未完成正式专业医学审稿。后续会继续根据读者、医生和相关专业人士反馈打磨全书阅读体验、医学边界和英文预览。

## 阅读边界

这本书只帮助读者理解风险语言、整理信息、准备就医沟通、识别危险信号、评估健康消费信息和建立家庭协作流程。

它不提供个体诊断、用药建议、停药建议、个体化筛查计划、个体化运动处方或治疗方案优先级。
