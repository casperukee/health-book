# Privacy

**Health Youpu / 健康有谱** is designed as a public reading project, not a personal health-record service.

Do not submit medical records, ID numbers, addresses, phone numbers, insurance information, report photos with personal information, or private family health details through GitHub issues, page feedback, comments, or email unless there is a clear reason and you have removed identifying details.

## Website Reading

The project has two main public reading surfaces:

- GitHub Pages: hosted by GitHub.
- Mainland-friendly mirror: hosted by the project maintainer.

The project itself does not require login, user accounts, cookies, or personal profiles.

## Mirror-Site Logs

The mirror site may use standard web server logs to understand whether the book is being read and which pages need improvement. These logs can include common technical fields such as IP address, user agent, requested URL, referrer, and timestamp.

The mirror site also has a lightweight feedback mechanism. Pageviews and footer-button clicks are recorded through a static asset request. The recorded event may include:

- action type, such as `pageview`, `useful`, `not_useful`, `share`, `comment`, `github_repo`, `github_star`, or `github_clone`;
- page path;
- page title;
- source label, such as mirror, GitHub Pages, local preview, or other;
- timestamp.

This mechanism is used for aggregate project improvement. It is not intended to collect personal health information.

## GitHub Issues And Public Feedback

GitHub issues and comments are public by default. Do not post private health details there.

Good feedback looks like:

> This section may make readers wait too long before seeing a doctor.

Avoid feedback like:

> Here is my family member's full report and ID information. What should we do?
