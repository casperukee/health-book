# Source Registry

This is the reader-facing source registry for the English web edition. It lists the public medical and consumer-health sources that currently calibrate the English adaptation.

The English edition is U.S.-first, so it gives priority to U.S. emergency pathways, public-health agencies, patient education, screening authorities, patient records, and consumer-protection sources when the topic depends on local systems. International sources are kept when they provide a stable global frame.

This page is not a guideline. It does not replace clinician judgment, emergency care, local public-health guidance, or the current version of any linked source.

Registry updated: 2026-06-28. Source links and medical guidance still need periodic review.

## Maintenance Rule

When an English page starts relying on a new public source for a medical boundary, U.S. care pathway, crisis line, screening authority, patient-record issue, medication boundary, device/test claim, or consumer-protection claim, add it here before linking readers to "the source registry."
