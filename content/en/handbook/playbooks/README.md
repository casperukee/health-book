## How To Choose

| Situation | Start with |
| --- | --- |
| Someone may need help now | [Red Flags](red-flags.md) |
| Symptoms are unclear, but there is no obvious red flag | [Symptom Action Guide](symptom-action-guide.md) |
| You do not know whether to use emergency care, urgent care, primary care, or a specialist | [Emergency, Clinic, or Which Department?](department-navigation-guide.md) |
| A preventive visit or checkup is coming | [Before a Checkup](checkup-planning-guide.md) |
| A clinic visit, urgent-care visit, or follow-up is coming | [Doctor Visit Checklist](doctor-visit-checklist.md) |
