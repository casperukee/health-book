# Feedback And Maintenance

This area is for feedback notes and review guidance. You do not need to read the whole book before giving feedback. One page and one honest reaction can already be useful.

- [Trial Reading And Feedback Guide](gray-trial-guide.md)

## If You Can Help Review

| Time available | How to help |
|---|---|
| 5 minutes | Open any page and check whether the title and first screen make the job clear |
| 10 minutes | Read one tool page and say whether you know the next step afterward |
| 20 minutes | Read one chapter and point out filler, repetition, alarmist wording, or unclear boundaries |
| 30 minutes | Put a real family situation through the entry page, chapter, and handbook flow |

The most useful feedback is not "looks good." It is:

- which sentence sounds like filler;
- which term is unclear;
- which situation is missing;
- where the tone feels uncomfortable or preachy;
- which page you would actually send to a family member.

See [Trial Reading And Feedback Guide](gray-trial-guide.md) for details.
