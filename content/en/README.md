# English Web Edition

**Health Decisions for Families** is an open-source health decision literacy book for families.

It helps ordinary families handle everyday health questions with less panic and more structure: when to seek urgent help, when to contact a clinician, how to prepare for a visit, how to keep basic health records, and how to slow down before acting on health claims.

This project is **not medical advice**. It does not diagnose, prescribe, recommend stopping medication, create individualized screening plans, or replace emergency care or clinician judgment.

## What This Edition Helps You Do

- Sort possible red flags before searching for disease names.
- Prepare useful facts before an appointment.
- Keep medication lists, allergies, prior reports, discharge instructions, and family contacts findable.
- Support parents, partners, children, older relatives, or chosen family without turning care into control.
- Read claims about supplements, tests, devices, and longevity services with more caution.
