# Playbooks 中文验收页

对应英文页：[Playbooks](../../../../en/handbook/playbooks/README.md)

这些页面适合行动流程和速查。

::: danger 先看危险信号
胸痛胸闷、疑似卒中、严重呼吸困难、意识改变、无法控制出血、突发剧烈疼痛、严重过敏、中毒、严重外伤、自伤或自杀风险、孕产期危险信号，先看 [Red Flags](../../../../en/handbook/playbooks/red-flags.md)。
:::

## 先看哪一页

| 场景 | 入口 |
|---|---|
| 已经可能出现危险信号，不确定能不能等 | [Red Flags](../../../../en/handbook/playbooks/red-flags.md) |
| 已经有症状，不知道下一步 | [Symptom Action Guide](../../../../en/handbook/playbooks/symptom-action-guide.md) |
| 情绪、焦虑、压力、失眠或自伤风险 | [Mental Health Check-In And Support](../../../../en/handbook/playbooks/mental-health-check-in.md) |
| 不知道该急诊、门诊还是找专科 | [Emergency, Clinic, or Which Department?](../../../../en/handbook/playbooks/department-navigation-guide.md) |
| 预防性就诊或体检要到了，不确定该讨论什么 | [Before A Checkup](../../../../en/handbook/playbooks/checkup-planning-guide.md) |
| 报告出现常见标红指标 | [Common Checkup Markers](../../../../en/handbook/playbooks/common-checkup-markers.md) |
| 想先约定哪些情况不能等 | [Red Flags](../../../../en/handbook/playbooks/red-flags.md) |
| 门诊、复诊或陪诊快到了 | [Doctor Visit Checklist](../../../../en/handbook/playbooks/doctor-visit-checklist.md) |

这些页面负责行动分流和沟通准备，不负责诊断。
