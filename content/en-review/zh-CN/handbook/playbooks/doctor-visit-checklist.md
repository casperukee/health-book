# Doctor Visit Checklist 中文验收页

本页是英文页面的中文验收辅助。它翻译/回译的是英文 adaptation，不是《健康有谱》中文版源稿。

> 本页不是医疗建议。出现胸痛胸闷、卒中样症状、严重呼吸困难、意识改变、无法控制出血、严重疼痛、自伤风险或其他危险信号时，先使用急救服务或急诊。不要为了整理清单延误就医。

门诊前不需要写长材料。把下面这些短表填进手机备忘录就够了。

## 30 秒开场

| 先说什么 | 一句话就够 |
| --- | --- |
| 这次就诊的主要原因 | 例如胸闷、腹痛、复查报告、调整用药 |
| 从什么时候开始 | 今天、三天前、两周前，还是反复很久 |
| 最近有什么变化 | 加重、变频繁、范围变大或出现新症状 |
| 最影响什么 | 睡觉、吃饭、走路、工作、上学、照护 |
| 最想问清什么 | 什么风险、什么检查、下一步或回家边界 |

## 就医前带什么

| 带什么 | 重点 |
| --- | --- |
| 最近报告 | 化验、影像、病理、出院小结；优先带异常和最新结果 |
| 用药和过敏 | 处方药、非处方药、补剂、草药、漏服停药、过敏史 |
| 关键趋势 | 血压、血糖、胆固醇、尿酸、肾功能、体重腰围；有用时带最近 1-3 次 |
| 既往背景 | 重大疾病、手术、急诊、家族史、孕产期、癌症治疗、重要诊断 |
| 三个问题 | 最想问清的 1-3 个问题，按顺序 |

准备拔牙、种牙、内镜、小手术或其他有创操作时，主动说明基础病和影响凝血、免疫、骨代谢或癌症治疗的用药。不要自行停药。

## 离开诊室前确认

| 问清什么 | 可以这样问 |
| --- | --- |
| 当前判断 | 现在最需要排除什么风险？还有什么不确定？ |
| 下一步 | 接下来是检查、用药、观察、复查，还是转诊？ |
| 回家边界 | 什么算预期恢复？什么情况要提前回来或去急诊？ |
| 复查计划 | 多久复查？之前要注意什么？需要带哪些资料？ |

## 陪诊人只做三件事

| 做什么 | 注意 |
| --- | --- |
| 补充事实 | 患者能说时，优先让本人说 |
| 记录下一步 | 记下检查、用药、复查和危险边界 |
| 把方案转成回家动作 | 谁买药、谁预约、谁记录、谁提醒 |

陪诊不是替患者做决定，而是帮助真实信息不掉在诊室外。

## 相关工具

- 有明显危险信号：先看 [Red Flags](red-flags.md)，必要时使用急救服务或急诊。
- 不知道该用哪个就医入口：看 [Care Entry And Specialty Navigation](department-navigation-guide.md)。
- 缺基础病、过敏、用药或联系人：先填 [One-Page Family Health Card](../templates/family-health-record.md#_1-one-page-family-health-card)。
