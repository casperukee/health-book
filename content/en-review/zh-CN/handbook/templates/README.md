# Templates 中文验收页

对应英文页：[Templates](../../../../en/handbook/templates/README.md)

这里放可复制填写的家庭健康模板。

## 先看哪一页

| 场景 | 模板 |
|---|---|
| 想先给家人做一张能马上用的健康卡 | [One-Page Family Health Card](../../../../en/handbook/templates/family-health-record.md#_1-one-page-family-health-card) |
| 想先为一个家庭成员建最小档案 | [Family Health Record And Chronic Marker Log](../../../../en/handbook/templates/family-health-record.md) |
| 想把长期指标按趋势整理给医生看 | [Chronic Marker Log](../../../../en/handbook/templates/family-health-record.md#_2-chronic-marker-log) |
| 体检报告有异常，想先看怎么分层 | [Common Checkup Markers](../../../../en/handbook/playbooks/common-checkup-markers.md) |
| 买健康产品前想先判断风险 | [Health Product Checklist](../../../../en/handbook/templates/health-product-checklist.md) |

模板的目标不是收集更多资料，而是让关键资料在就医、复查、照护和消费决策时能被快速找到。
