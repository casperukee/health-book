# Errata 中文验收页

本页是英文勘误页的中文验收辅助。它翻译/回译的是英文页面当前给读者看的内容，不是中文版源稿。

## 勘误页

英文版把勘误、医学事实复查和来源处理规则保留在自己的闭环里。

这些页面是维护记录，不是医疗建议。涉及读者安全的问题优先级高于纯表达修改。

## 优先级

最优先修订的是可能影响读者安全的措辞：危险信号、用药边界、筛查表述、心理危机资源、儿童和老年人，以及补剂、设备、检测或抗衰服务宣称。
