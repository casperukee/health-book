# 英文总入口中文验收页

对应英文页：[English Web Edition](../../en/README.md)

本页是英文版入口页的中文验收辅助，用来检查英文 adaptation 的含义、语气、本土化处理和医学边界。它不是《健康有谱》中文版源稿，也不是中文版主书的替代入口。

## 英文网页版

**Health Youpu / 健康有谱** 是一本面向家庭的开源健康判断力读本。

英文版正在以中文版 `v1.0.0` 为源版本，重建为一个**美国优先的网页版 adaptation**。它不是逐句翻译。目标是在保留同一套家庭健康判断系统和医学边界的同时，针对英语读者重新处理例子、就医路径、单位、来源锚点和家庭协作场景。

当前英文页仍应视为基础预览，而不是完整英文书。

## 这一版服务谁

这一版帮助读者更冷静地处理实际健康问题：

- 什么时候该打急救电话、去急诊、用 urgent care、联系 primary care，什么时候可以记录观察；
- 就医前怎样准备有用事实，而不是带着猜测和零散截图去问医生；
- 怎样把用药清单、过敏史、既往报告、出院说明和家庭联系人从各种 portal 和聊天记录里整理出来；
- 怎样支持父母、伴侣、孩子、年长亲属或 chosen family，同时不把关心变成控制；
- 怎样看待健康宣称、保健品、检测、设备和抗衰营销，不把自信的话术误当作证据。

这个项目**不是医疗建议**。它不诊断、不开药、不建议停药、不制定个体化筛查计划，也不能替代急救、急诊或医生判断。

## 美国优先，但保留可迁移性

第一版英文 adaptation 面向美国读者写作，因此会在需要时使用美国读者熟悉的就医路径和表达：

- 911、emergency department、urgent care、primary care、specialist referral、telehealth、pharmacy、discharge instructions 和 return precautions；
- preventive care、patient portal、medication reconciliation，以及 insurance、network status、copay、deductible、prior authorization 等现实摩擦；
- 美国化验报告中常见的单位和表达，例如 mg/dL、mmHg；
- CDC、NIH、MedlinePlus、USPSTF、AHA/ACC、ADA、NCI、NIA、NIMH、SAMHSA、FDA、FTC、NCCIH、WHO 等英文权威来源。

美国以外的英语读者仍可使用这些判断模型，但需要把急救电话、就医路径、筛查建议、保险规则和公共卫生来源映射到自己所在国家或地区。

## 当前工作顺序

英文网页版会分阶段重建：

1. **安全和入口包：** start here、medical boundaries、red flags、symptom actions、visit preparation、family health card。
2. **体检和风险语言：** healthspan、risk curves、checkup markers、preventive-care planning、common abnormal markers、chronic marker logs。
3. **身体主风险线：** metabolic、cardiovascular、sleep、mental health、cancer、specialty care 等核心章节。
4. **家庭健康操作系统：** records、visit preparation、parent conversations、elder care、privacy、consent、portals、long-distance caregiving。
5. **健康信息防御：** supplements、devices、tests、longevity marketing、health news、consumer-protection boundaries。

英文读书版应放在后面，等网页版完成 adaptation、审校并稳定后再考虑。
