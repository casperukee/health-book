# 英文总入口中文验收页

本页是英文版入口页的中文验收辅助。它翻译/回译的是英文页面当前给读者看的内容，不是《健康有谱》中文版源稿。

## 英文网页版

**Health Decisions for Families** 是一本面向家庭的开源健康判断力读本。

它帮助普通家庭更有章法、少一点慌乱地处理日常健康问题：什么时候需要尽快求助，什么时候联系医生，就医前怎样准备，怎样保存基础健康资料，以及面对健康宣称时怎样慢下来。

这个项目**不是医疗建议**。它不诊断、不开药、不建议停药、不制定个体化筛查计划，也不能替代急救、急诊或医生判断。

## 这一版帮助你做什么

- 搜疾病名之前，先分辨可能的危险信号。
- 就诊前准备有用事实。
- 让用药清单、过敏、既往报告、出院说明和家庭联系人找得到。
- 支持父母、伴侣、孩子、年长亲属或 chosen family，同时不把关心变成控制。
- 更谨慎地阅读保健品、检测、设备和抗衰服务的宣称。
