# 英文版中文验收页

这里放英文版的中文验收页。

这些页面不是《健康有谱》中文版源稿，也不是中文版主书的替代入口。它们是为了让维护者在手机上检查英文 adaptation 的含义、语气、医学边界和本土化处理。

规则：

- 正式英文内容仍放在 `content/en/`，并使用英文写作；
- 中文验收页放在 `content/en-review/zh-CN/`；
- 中文验收页应尽量对应英文页面路径；
- 中文验收页翻译的是英文 adaptation，不直接复制原始中文章节；
- 每次英文页面更新后，应同步更新对应中文验收页；
- 英文页面可以放一个低调的 `中文验收页` 链接，方便手机检查；
- 这些页面不进入主导航，除非后续需要单独做验收目录。

第一批建议建立对应验收页：

- `book/00-start-here.md`
- `book/medical-boundaries.md`
- `handbook/playbooks/red-flags.md`
- `handbook/playbooks/symptom-action-guide.md`
- `handbook/playbooks/doctor-visit-checklist.md`
- `handbook/templates/family-health-card.md`
