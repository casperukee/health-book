# English Main Book 中文验收页

对应英文页：[English Main Book](../../../en/book/README.md)

本页是英文主书目录页的中文验收辅助。它翻译/回译的是英文页面当前给读者看的内容，不是《健康有谱》中文版主书目录。

> 本书不是医疗建议。出现危险信号时，请及时就医。

Health Decisions for Families 写给经常需要为自己和家人做健康判断的人：看体检报告、陪父母就医、帮孩子或伴侣分急缓、管理慢病记录、识别补剂和短视频健康内容里的诱导。

建议从 [Start Here](../../../en/book/00-start-here.md) 开始连续阅读。每章末尾都有上一章 / 下一章导航；网页版也提供侧边栏、搜索和页面大纲。

主书已经从“工具箱”进一步变成一本家庭健康判断读本：理解身体信号，做出更好的选择。网页版仍支持按需查阅，同时强化从身体信号、风险线、家庭协作到信息防御的连续旅程。

## 阅读旅程

本书不是按医学专科组织，而是按普通家庭真正遇到健康问题的顺序展开：

1. **身体在说什么。** 先知道什么不能等，再理解健康寿命、风险曲线和体检指标。
2. **值得盯住的主要风险线。** 代谢、心血管风险、睡眠、大脑和心理健康、癌症、专科问题，是家庭会反复遇到的风险线。
3. **健康变成家庭事务。** 很多健康问题最后会落到资料、陪诊、随访、父母沟通和照护角色。
4. **不要被健康信息牵着走。** 补剂、设备、检测、抗衰营销、新研究和短视频会不断干扰家庭判断。
