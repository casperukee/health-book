# 第三章 当健康变成一家人的事

本部分把健康判断转成家庭可执行流程。

健康问题一旦进入家庭，就不只是“知道什么”了。现实问题通常是：报告找不到、老人说不清、门诊时间短、父母不想被管、子女异地、慢病复查没人记、照护分工说不出口。

本部分不替家庭做决定，而是帮家庭把几个关键流程提前说清：

- 家庭健康系统到底要管理哪些事实、边界、下一步和分工；
- 就医前怎样把症状、病史、用药和问题带进诊室；
- 和父母谈健康时，怎样少一点评判，多一点共同准备；
- 老年健康如何从单个指标扩展到行动、认知、用药、生活能力和照护者支持。

这一部分接在身体风险线之后，是因为很多健康风险最后都要靠家庭流程才能真正落地。
