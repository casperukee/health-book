# 第二章 你最该盯住的几条风险线

本部分按长期风险线组织身体问题。

家庭很容易被单点问题牵着走：一个胆固醇异常标记、一阵胸闷、连续几周睡不好、父母记忆变化、影像发现结节，或者某个看起来需要专科的症状。单点当然重要，但真正决定下一步的通常是：它属于哪条风险线，是否急，是否持续影响功能，是否需要专科判断。

这一章不需要一口气读完。前两节适合顺着读：先看血压、胆固醇和甘油三酯、血糖/A1C、尿酸为什么常常连在一起，再看心梗和卒中为什么很少是真的突然发生。如果读完前两节后，你更关心“还没变成病时，日常还能往哪里调”，可以直接跳到第三节“共同上游”。后面的睡眠、大脑心理、癌症、儿童青少年和专科问题，可以按眼前最关心的事进入。

这一部分大致按这样的顺序展开：

1. 先看代谢和心血管风险，因为它们连接体检指标、慢病、心梗和卒中；
2. 再看共同上游，把活动、吃喝、恢复、压力和反馈放回可持续的日常默认值；
3. 再看睡眠恢复和大脑心理，因为它们决定白天功能、长期能力和家庭安全边界；
4. 最后看癌症严重疾病、儿童青少年和专科问题，把高焦虑主题和特殊人群放回阶段判断、资料准备和专业协作。

读完这一部分，下一步不是自己当医生，而是把判断转成家庭流程：谁记录、谁陪诊、谁复查、谁把正确的信息带给临床人员。

如果按顺序读，直接从代谢和心血管开始即可；如果回头查某个问题，先看每页的二级标题、危险边界、观察卡、门诊问题和小结。具体症状下一步、就医入口和门诊准备，放在手册页里承接，主书正文不重复做工具页。
