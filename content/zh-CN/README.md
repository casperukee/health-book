# 健康有谱中文版

> 本书不是医疗建议。出现危险信号时，请优先联系当地急救服务或及时就医。

《健康有谱》是一本面向家庭的长期健康判断读本，帮助你把体检报告、危险信号、就医准备、家庭健康资料和健康消费信息放进同一套判断系统里。
