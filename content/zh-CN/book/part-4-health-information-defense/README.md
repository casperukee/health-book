# 第四章 别被忽悠：健康信息防御系统

本部分处理健康判断的外部干扰。

当家庭开始认真管理健康以后，最容易遇到的不是信息太少，而是信息太多：保健品宣传、体检中心加项、手表和设备分数、抗衰检测、短视频新研究、家庭群里的“专家说”。这些信息常常不直接骗人，而是把机制、指标、案例和恐惧拼在一起，让人想立刻花钱或立刻改变生活。

本部分的目标是让全家健康守门人先慢下来：

- 保健品先看监管边界、人体证据、产品形态和替代关系；
- 设备和检测先问“能测、测准、有用、值得买”是否都成立；
- 健康新闻和短视频先问它想让你做什么，再看证据层级。

明确立场：凡是夸大承诺、制造恐惧、替代正规医疗、诱导高价连续消费的健康营销，都不应成为家庭健康决策的主入口。
