# 中文主书目录

> 本书不是医疗建议。出现危险信号时请及时就医。

《健康有谱》写给经常需要替自己和家人做健康判断的人：看体检报告、陪父母就医、帮孩子或伴侣分急缓、处理慢病资料、识别保健品和健康短视频里的诱导。

推荐从 [如何使用这本书](00-start-here.md) 开始连续阅读。每章末尾都有“上一章 / 下一章”导航；网页阅读版还会提供侧边栏、搜索和页面大纲。

当前主书已经从“工具箱”进一步升级为“给全家健康守门人的判断指南”。网页继续保留按需查阅能力，同时强化从身体信号、风险线、家庭协作到信息防御的连续阅读旅程。

## 这本书的阅读旅程

这本书不是按医学科室展开，而是按普通家庭真正遇到问题时的顺序展开：

1. **身体在说什么。** 先知道什么情况不能等，再理解健康寿命、风险曲线和体检指标。
2. **你最该盯住的几条线。** 代谢、心血管、睡眠、大脑心理、癌症和专科问题，是家庭最容易反复遇到的主风险线。
3. **健康变成一家人的事。** 很多健康问题最后都会落到资料、陪诊、复查、父母沟通和照护分工。
4. **别被健康信息牵着走。** 保健品、设备、检测、抗衰营销、新研究和短视频，会不断干扰家庭判断。
