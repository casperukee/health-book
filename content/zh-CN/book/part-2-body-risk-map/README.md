# 第二章 你最该盯住的几条线

本部分按长期风险线组织身体问题。

普通家庭最容易被单点问题牵着走：一个血脂箭头、一阵胸闷、连续失眠、父母记忆变差、体检发现结节、某个专科症状反复不好。单点当然重要，但真正决定下一步的是：它属于哪条风险线，是否急，是否持续影响功能，是否需要专科判断。

这一章不需要一口气读完。前两节适合顺着读：先看四高为什么常常连在一起，再看心梗和卒中为什么不是突然发生。如果读完前两节后，你更关心“还没变成病时，日常还能往哪里调”，可以直接跳到第三节“共同上游”。后面的睡眠、大脑心理、癌症、儿童青少年和专科问题，可以按你眼前最关心的事进入。

这一部分大致按这样的顺序展开：

1. 先看代谢和心血管，因为它们连接体检指标、慢病、心梗和卒中；
2. 再看共同上游，把活动、吃喝、恢复、压力和反馈放回可持续的日常默认值；
3. 再看睡眠恢复和大脑心理，因为它们决定白天状态、长期功能和家庭安全边界；
4. 然后看癌症重大疾病、儿童青少年和专科问题，把高焦虑主题和特殊人群放回阶段判断、资料准备和专业协作。

读完这一部分，下一步不是自己当医生，而是把判断转成家庭流程：谁记录、谁陪诊、谁复查、谁把信息带给医生。

如果按顺序读，直接从代谢和心血管开始即可；如果回头查某个问题，优先看每章的二级标题、危险边界、观察卡、门诊问题和“小结”。具体症状下一步、挂号入口和门诊准备，放在手册页里承接，主书正文不重复做工具页。
