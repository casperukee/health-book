# 专科问题：如何提高看病质量，而不是自己当医生

> 本文不是医疗建议。视力突然下降、孕产期危险信号、严重外伤、剧烈疼痛、尿血发热、意识改变或神经症状等情况，请及时就医或急诊。

## 专科问题最怕的，不是问得多，而是关键事实没说出来

眼睛不舒服，觉得少看手机就好；尿频尿急，不好意思讲；腰腿痛，靠按摩和膏药撑着；孕期不适，被说成“都这样”；月经、盆腔、产后、更年期问题，拖到影响生活才去看。

专科问题有两个常见极端：一个是忍，另一个是在网上看了很多内容后开始自我诊断。

更好的位置在中间：你不需要先知道自己是什么病，但要知道什么时候不能等、该从哪个入口看、怎样描述症状、门诊结束前要问清什么。

## 别把羞耻感、习惯和忍耐当成医学判断

专科问题很容易被“这不严重”“不好意思说”“忍一忍”“网上说像某个病”带偏。

- 泌尿、妇科、产后、性健康问题，越不好意思，越需要用事实说清；
- 腰背痛、关节痛、眼干、皮肤、睡眠和排尿问题，越常见，越不能自动等于不重要；
- 老人、孕产妇、儿童、慢病患者和多药使用者，同样症状的风险边界可能不同；
- 自己查资料可以帮助提问，但不能替代查体、检查和医生判断。

普通人要学的不是诊断名，而是准确描述身体发生了什么。

## 一张症状小卡，比十个猜测更有用

门诊前先写一张小卡。

| 要写什么 | 怎么写更有用 |
| --- | --- |
| 时间 | 什么时候开始，是突然还是慢慢加重，持续多久 |
| 位置 | 具体在哪里，是否会转移或放射到别处 |
| 性质 | 胀、刺、压、烧灼、麻、痒、绞痛、跳痛，还是说不清 |
| 程度 | 0-10 分大概几分，是否越来越重 |
| 诱因和缓解 | 活动、进食、姿势、排尿、月经、睡眠、压力、用药后是否变化 |
| 功能影响 | 是否影响看东西、走路、睡眠、工作、吃饭、排尿、性生活、照护 |
| 伴随情况 | 发热、出血、麻木无力、头晕、气短、皮疹、体重变化、情绪变化 |
| 已做什么 | 用过什么药、膏药、保健品、理疗、设备，效果和副作用如何 |

这张小卡不是让你“像医生一样说话”，而是让医生少花时间猜背景，多花时间判断下一步。

## 五类常见入口

### 1. 眼科：先看视力和疼痛变化

眼睛问题不要只说“眼睛不舒服”。先分清：视力有没有突然下降，视野有没有缺损，是否眼痛、红眼、外伤、异物、头痛恶心，是否有糖尿病、高血压或长期用药。

视力突然变化、眼外伤、眼痛伴头痛恶心、红眼伴视力下降，不适合拖着观察。

### 2. 骨科和运动系统：先看功能和神经信号

腰背痛、颈肩痛、膝痛、运动损伤，最重要的是功能有没有变：能不能站、走、负重、抬手、转身，是否麻木无力，是否伴发热、外伤、大小便异常。

按摩、理疗、贴膏药可以缓解一些轻症不适，但如果疼痛加重、功能下降、出现神经症状或外伤后不能负重，要尽快就医。

### 3. 泌尿：别只说“上火”或“肾虚”

排尿问题要说清：尿频、尿急、尿痛、尿血、夜尿、漏尿、排不出、腰痛发热，分别出现多久，是否影响生活。

尿血、发热伴腰痛、明显排尿困难、剧烈疼痛，不适合只喝水或自行用药。

### 4. 孕产和女性健康：不要被“都这样”盖过去

月经、备孕、孕期、产后、更年期，都有自己的风险边界。异常大量出血、严重腹痛、发热、孕产期严重头痛、视物异常、胸痛气短、胎动明显异常，需要及时医学判断。

更常见但长期影响生活的问题，如月经紊乱、痛经、盆腔不适、产后漏尿、睡眠情绪和更年期症状，也值得门诊讨论，而不是靠忍耐。

### 5. 皮肤、牙科、耳鼻喉和其他专科：看持续、复发和影响

皮疹、痤疮、鼻炎、耳鸣、牙痛、口腔问题、甲状腺、消化、疼痛等，都不需要一开始就懂专业诊断。先记录持续多久、反复频率、照片变化、用过什么、是否影响睡眠工作和生活。

如果出现快速加重、发热、严重疼痛、感染扩散、吞咽呼吸困难、明显出血或全身状态变差，要提高急缓等级。

## 门诊结束前，问清四句话

不要只问“我到底是什么病”。更实用的是：

1. 现在最需要排除的风险是什么？
2. 这次检查或治疗要回答什么问题？
3. 哪些情况要提前回来或急诊？
4. 如果 1-2 周、1 个月或一个疗程后没改善，下一步怎么走？

这四句话能把门诊从“听医生说完”变成“知道回家怎么做”。

## 不适合继续观察的情况

以下情况不适合继续观察：

- 症状突然出现、快速加重或影响基本功能；
- 伴随发热、异常出血、严重疼痛、外伤、意识改变或神经症状；
- 孕期或产后一年内出现明显异常；
- 尿血、排尿困难、视力变化、行动能力下降；
- 自行用药、按摩、理疗、草药、补剂或设备后症状加重；
- 医生交代的提前复诊条件已经出现。

## 今天可以做的准备

- 选一个正在困扰你的专科问题，写一张症状小卡；
- 把既往检查、用药、外用产品、保健品和照片整理到 [家庭健康档案模板](../../handbook/templates/family-health-record.md)；
- 门诊前只准备 3 个最重要的问题；
- 看完医生后记录：诊断或暂定判断、检查、用药、复查时间、提前就医边界。
