# 勘误、更新与反馈

> 健康科普书不应该假装自己永远正确。医学资料会更新，表达也可能有疏漏；重要的是把修订机制公开，并且把读者安全放在第一位。

## 当前版本说明

本书第一版完成于 2026-06-08；当前稿件已更新至 2026-06-15 这轮内容修订与附录边界校准。

它已经形成完整阅读结构，但仍需要继续做三件事：

- 医学边界复核；
- 版式和移动端阅读检查；
- 读者反馈后的表达修订。

在这些工作完成前，本书不应被当作医学定稿、临床指南或个体化建议。

最新在线版本和勘误记录会优先更新在项目页面：[http://health.mindarae.com](http://health.mindarae.com)。

详细勘误记录见 [勘误记录](corrections.md)，医学事实复查记录见 [医学事实复查记录](review-log.md)，来源处理规则见 [来源处理规则](source-policy.md)。

## 什么问题值得反馈

如果你在阅读中发现以下问题，建议记录下来：

- 医学事实错误；
- 危险信号或就医边界不清；
- 表述过度确定，可能让人自我诊断、自行用药或延误就医；
- 来源、机构或链接信息过期；
- 某个清单在真实家庭场景里不好用；
- 章节读起来重复、跳跃或不自然；
- 表格、清单或附录在手机阅读时不清楚；
- 版权、引用或致谢表达不妥。

## 修订优先级

最优先处理的是会影响读者安全的内容：

- 急症和危险信号；
- 用药、停药、治疗、筛查和复诊边界；
- 慢病指标和重大疾病相关表述；
- 心理危机、孕产期、儿童和老年健康；
- 可能被健康产品营销利用的模糊表述。

其次处理来源更新、链接失效、术语不一致、章节重复和版式问题。

## 一句话

一本可靠的健康科普书，不是没有错误，而是愿意公开修订，并且始终把边界说清楚。
