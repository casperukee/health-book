# 勘误、更新与反馈

> 健康科普书不应该假装自己永远正确。医学资料会更新，表达也可能有疏漏；重要的是把读者安全放在第一位。

本书会继续根据医学资料更新、专业审读意见和真实阅读反馈修订。最新在线版本和勘误记录会优先更新在项目页面：[https://health.mindarae.com](https://health.mindarae.com)。

当前网页版为 v0.9.3，已经完成一轮主书和手册内容同步。它仍然不是医疗建议、临床指南或个体化方案。

如果你在阅读中发现以下问题，欢迎反馈：

- 医学事实错误；
- 危险信号或就医边界不清；
- 表述可能让人自我诊断、自行用药或延误就医；
- 来源、机构或链接信息过期；
- 某个清单在真实家庭场景里不好用；
- 章节读起来重复、跳跃或不自然；
- 表格、清单或附录在手机阅读时不清楚；
- 版权、引用或致谢表达不妥。

最优先修订的，是可能影响读者安全的内容：急症和危险信号，用药、停药、治疗、筛查和复诊边界，心理危机、孕产期、儿童和老年健康，以及可能被健康产品营销利用的模糊表述。

详细勘误记录见 [勘误记录](corrections.md)，医学事实复查记录见 [医学事实复查记录](review-log.md)，来源处理规则见 [来源处理规则](source-policy.md)。

一本可靠的健康科普书，不是没有错误，而是愿意修订，并且始终把边界说清楚。
