# v0.9 试读与反馈说明

谢谢你愿意帮忙试读《健康有谱》。当前版本是 v0.9，可以连续阅读，也可以按场景查工具页。它适合帮忙挑问题、看阅读体验、看医学边界是否稳妥，不适合作为医疗建议传播。

## 先看边界

这本书不提供诊断、用药、停药、筛查或治疗建议，也不能替代医生。出现胸痛、卒中样症状、严重呼吸困难、晕厥、意识改变、严重疼痛、异常出血、自伤或自杀风险等危险信号时，请及时联系当地急救服务或就医。

试读时如果你正在面对具体健康问题，请优先使用医生、急诊、当地医疗热线或可信医学机构资料。本书只帮助你整理问题、判断急缓、准备沟通和识别信息陷阱。

## 推荐试读路径

不需要从头读完整本。建议按你最有感的场景选一条路径。

| 你现在想做什么 | 先试读 |
|---|---|
| 身体已经不舒服，不确定能不能等 | [危险信号速查](../handbook/playbooks/red-flags.md)；如果不是明显急症，再看 [症状与对应动作速查](../handbook/playbooks/symptom-action-guide.md) |
| 要看报告、复查或见医生 | [体检指标](../book/part-1-healthspan-risk-and-markers/checkup-markers.md) 或 [就医前问题清单](../handbook/playbooks/doctor-visit-checklist.md) |
| 想给家人做准备 | [一页家庭健康卡](../handbook/templates/family-health-record.md#_1-一页家庭健康卡)，再看 [家庭健康档案与慢病记录](../handbook/templates/family-health-record.md) |
| 想系统读一遍 | [如何使用《健康有谱》](../book/00-start-here.md)，再进入 [中文主书目录](../book/README.md) |
| 家里有人买保健品、检测或抗衰产品 | [健康产品购买前检查清单](../handbook/templates/health-product-checklist.md)，再看 [保健品证据陷阱](../book/part-4-health-information-defense/supplement-evidence-traps.md) |

如果只能读 20 分钟，优先读：

1. [如何使用《健康有谱》](../book/00-start-here.md)
2. 选择一个最贴近你生活的章节或工具页；
3. 读完后反馈：入口是否顺、下一步是否清楚、哪里还像套话，哪里读起来不像一本书。

## 只读一页也可以

很多反馈不需要完整读完一本书。你只要挑一页，边读边记一句真实反应，就已经很有价值。

| 你有多少时间 | 怎么读 | 最值得反馈什么 |
|---|---|---|
| 5 分钟 | 随手打开一页，扫标题和表格 | 有没有一眼知道这页是干什么的 |
| 10 分钟 | 读一个工具页，比如症状速查或家庭健康卡 | 读完是否知道下一步怎么做 |
| 20 分钟 | 读一章正文，再读一个相关工具页 | 正文和工具是否接得上 |
| 30 分钟 | 代入一个真实家庭场景跑一遍 | 哪一步卡住、缺什么、哪里不敢照做 |

## 试读时重点看什么

请尽量不要只反馈“写得好不好”。更有价值的是这几个问题：

1. 你打开页面后，是否能快速找到下一步该看哪里？
2. 读完之后，你是否更清楚“记录、观察、复查、就医、急诊”怎么区分？
3. 哪些地方太泛、太像正确废话，或者读完仍然不知道怎么做？
4. 哪些表达让你觉得被说教、被吓到，或像在替你做医疗决定？
5. 哪些内容对你真实有用，值得继续扩展成工具、清单或模板？
6. 如果你连续读一章，是否像有人陪你思考，还是像在查资料？

## 最有用的反馈长什么样

不用写正式评审。下面这种短反馈最有帮助：

| 反馈类型 | 例子 |
|---|---|
| 像套话 | “这一段我读完觉得对，但不知道能做什么。” |
| 不够准确 | “这里把胸闷和胸痛放一起，我不确定会不会误导。” |
| 场景没覆盖 | “如果老人不是独居，而是和子女住一起，这里也适用吗？” |
| 读不下去 | “前面三段太长，我在手机上看到这里就想划走。” |
| 术语不懂 | “NSDR、CBT-I 这两个词我不知道是什么意思。” |
| 有用 | “这张表我愿意发给家人，因为它不像在教育人。” |

如果只能反馈一句，就写：

```text
我读到这里的真实反应是：
```

## 作者最想知道的三件事

- 这本书的入口是否顺：你能不能在 1-2 次点击内进入需要的内容？
- 工具页是否真能用：症状速查、体检工具、就医清单、家庭健康卡和健康产品清单是否足够具体？
- 主书是否值得读：它是不是只像资料整理，还是能帮你形成更稳定的健康判断？尤其是大脑心理、儿童青少年、癌症和专科问题这些章节，是否既能读下去，又不越过医疗边界？

## 当前版本说明

v0.9 已经形成可连续阅读的中文主书和可按场景使用的手册页。本轮重点统一了正文内容、医学边界、案例表达和网页阅读体验，同时保留危险信号、症状速查、体检工具、就医清单、家庭健康卡和健康产品核查等工具入口。它仍不是医疗建议，也还没有完成正式专业医学审稿；后续会根据读者和专业人士反馈继续打磨全书阅读体验、英文预览和高风险医学边界。
