# 健康产品购买前检查清单

> 本清单不是医疗建议，也不是产品推荐。任何产品、设备、检测或服务都不能替代医生诊断、治疗、用药、复查、筛查或急救判断。

## 这页怎么用

适用于准备购买：

- 保健品、草药、营养补剂；
- 健康设备、睡眠仪、家用检测、可穿戴设备；
- 基因检测、微生态检测、抗衰检测；
- 抗衰产品、美容仪、疗程、养生服务；
- 父母健康讲座、会员、社群和高价套餐。

目标不是把每个产品都研究成论文，而是在购买前判断：这是普通消费、需要问医生，还是应该及时阻断。

如果你想先理解保健品为什么容易让家庭误判，可以读主书的 [保健品最常见的证据陷阱](../../book/part-4-health-information-defense/supplement-evidence-traps.md)。如果产品属于检测、设备或抗衰营销，可以读 [设备、检测和抗衰营销怎么判断值不值](../../book/part-4-health-information-defense/devices-tests-and-longevity-marketing.md)。

## 一句话原则

健康产品购买前先判断风险级别，再决定是可以买、缓买、问医生，还是不买。

## 30 秒阻断规则

只要命中下面任意一条，先不要付款：

- 要求停药、拒绝复查或替代正规治疗；
- 承诺治愈、逆转、根治、清除重大疾病风险；
- 高价、限时、入会、拉人、返利或投资；
- 要求隐瞒家人，或不让你带给医生看；
- 涉及老人、儿童、孕产、慢病、肝肾问题、癌症、精神心理疾病或多药使用。

先停下来，不等于永远不买。它只是把“立即付款”改成“先查证、问医生、和家人商量”。

## 3 分钟暂停

如果你已经被种草、焦虑或限时优惠推着走，先做一个 3 分钟暂停：

1. 不付款，不转账，不填健康信息；
2. 把手机放下，慢慢呼吸几轮；
3. 写下这个产品承诺解决什么问题；
4. 问自己：它会不会替代复查、就医、睡眠、运动、饮食或用药安全？

这不是冥想课，也不是让你否定所有产品。它只是把冲动购买变成可检查的健康决策。

## B. 风险分级

勾选最接近的一档。

- [ ] 低风险：价格低，不替代治疗，不影响用药，只是提醒、记录或心理安慰。
- [ ] 需要确认：老人、儿童、孕产、慢病、正在用药、肝肾问题、手术前后，或检测结果可能影响决策。
- [ ] 暂缓购买：价格高、证据不清、结果难解释、隐私风险大、宣传明显夸张。
- [ ] 高风险阻断：承诺治病、要求停药、替代治疗、拒绝复查、入会拉人、投资返利、隐瞒家人。
- [ ] 紧急处理：已经大额付款、借钱、停药、拒绝就医或被要求保密。

## C. 七个核查问题

### 1. 它到底是什么？

- [ ] 食品/保健品
- [ ] 药品
- [ ] 医疗器械
- [ ] 家用监测设备
- [ ] 直接面向消费者的检测
- [ ] 美容/抗衰/养生服务
- [ ] 课程、社群或会员

如果商家自己说不清类别，先暂停。

### 2. 它是在补充，还是在治疗？

- [ ] 只是补充缺乏的营养或做行为提醒；
- [ ] 暗示改善症状；
- [ ] 宣称治疗、逆转、预防重大疾病；
- [ ] 暗示可以替代药物、检查或医生。

越像治疗，证据要求越高。

### 3. 证据是什么？

- [ ] 只有机制故事；
- [ ] 只有细胞或动物研究；
- [ ] 只有达人体验或用户反馈；
- [ ] 有人体研究，但人群和我不相似；
- [ ] 有随机对照人体研究；
- [ ] 有官方指南、专业协会或医生明确建议。

“有研究”不是结论。要看研究对象、终点、样本量、随访时间和是否能改变行动。

### 4. 产品和研究是不是同一个东西？

- [ ] 剂量清楚；
- [ ] 成分清楚；
- [ ] 纯度和批次清楚；
- [ ] 产品形态和研究一致；
- [ ] 标签、禁忌、风险提示清楚；
- [ ] 没有混合很多难以判断的成分。

从实验室到购物车，中间可能断裂。

### 5. 有没有医疗和用药风险？

- [ ] 正在使用处方药；
- [ ] 有高血压、糖尿病、心血管病、肾病、肝病、癌症或精神心理疾病；
- [ ] 正在备孕、怀孕、哺乳；
- [ ] 近期手术、拔牙或侵入性操作；
- [ ] 老人、儿童或多药使用者；
- [ ] 服用后可能影响血压、血糖、凝血、睡眠、情绪或肝肾功能。

命中任一项，购买前先问医生或药师。

### 6. 它会不会替代真正该做的事？

- [ ] 替代睡眠、运动、饮食和复查；
- [ ] 替代医生诊断；
- [ ] 替代标准筛查；
- [ ] 替代药物或治疗；
- [ ] 让人推迟就医；
- [ ] 让家庭把钱和精力从更重要的事情上移走。

健康产品一旦替代正规医疗，就不是普通消费。

### 7. 钱和隐私是否可控？

- [ ] 单次价格可承受；
- [ ] 没有长期自动续费；
- [ ] 没有贷款、投资、返利或拉人头；
- [ ] 不要求上传过多个人和家庭健康信息；
- [ ] 可以退出；
- [ ] 家人知道购买内容和金额。

## D. 决策

- [ ] 可以买：低价、低风险、不替代治疗，且知道它只是辅助。
- [ ] 先缓买：还没看清证据、价格、风险或替代成本。
- [ ] 先问医生/药师：涉及疾病、用药、孕产、儿童、老人、手术或检测结果。
- [ ] 不买：夸大疗效、高价、传销、替代治疗、隐瞒家人。
- [ ] 需要家庭干预：已经停药、拒绝复查、大额付款、借钱、被社群控制。

## E. 替代行动

如果决定不买或暂缓，可以把钱和行动转到更稳的地方：

- [ ] 安排一次正规复查或门诊；
- [ ] 整理慢病指标记录表；
- [ ] 更新家庭健康档案；
- [ ] 购买可靠的基础测量工具，例如合适的血压计，并学习正确测量；
- [ ] 先做一个不花钱的底座动作：每天 5-10 分钟轻活动，或睡前 3 分钟呼吸觉察；
- [ ] 改善睡眠、运动、饮食、牙齿、疫苗和戒烟限酒；
- [ ] 陪父母散步、复查、问医生，而不是只争对错。

## 家庭约定

建议提前约定三条规则：

- 超过家庭约定金额的健康消费，至少冷静 24 小时；
- 涉及疾病、用药、检测、治疗或筛查的产品，先问医生或药师；
- 父母想买时，子女先帮忙查证和替代行动，不只说“没用”。

## 最后提醒

健康产品最怕的不是买错一个东西，而是让一个东西替代了真正该做的健康行动。
