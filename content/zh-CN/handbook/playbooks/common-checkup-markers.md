# 常见异常指标速查

> 本页不是医疗建议，不能替你解释个人报告、诊断疾病、决定用药或停药。化验结果需要结合症状、病史、体征、既往结果、用药和医生判断。

这页适合拿到体检报告后快速扫一遍：某个异常大概在提示什么，它容易被什么误解，下一步该记录、复查还是问医生。

## 常见指标怎么看

| 指标 | 它大概提示什么 | 先别怎么理解 | 下一步动作 |
|---|---|---|---|
| 血压 | 血管长期负荷、心脑肾风险线索 | 不要用一次门诊或体检读数直接给自己定性 | 按规范复测；记录时间、姿势、休息、情绪、咖啡、运动和用药 |
| 血脂 | LDL、HDL、甘油三酯和总胆固醇共同提示脂质运输与心血管风险 | 不要只看“总胆固醇”或一个红箭头 | 和年龄、血压、血糖、吸烟、家族史、既往心血管病一起问总体风险 |
| 血糖 | 空腹血糖看当时状态，A1C 看过去数月平均血糖线索 | 空腹正常不等于餐后和长期代谢完全没问题；A1C 也不是所有人都准确 | 记录空腹/餐后/A1C 类型；有风险或反复异常时问是否需要复查或糖耐量测试 |
| 尿酸 | 嘌呤代谢、痛风、肾结石和肾脏排泄线索 | 不要只归因于海鲜啤酒，也不要只盯一次数字 | 同时看肾功能、血压、血脂、血糖、体重、饮酒、甜饮料和痛风发作史 |
| 肾功能 | 肌酐、eGFR、尿蛋白/尿白蛋白提示过滤和肾损伤线索 | 肌酐正常不等于肾脏一定没风险；eGFR 也要看年龄、肌肉量和持续性 | 糖尿病、高血压、心血管病或家族史人群，重点问 eGFR 和尿白蛋白/尿蛋白 |
| 肝功能 | 肝酶、胆红素、白蛋白等提示肝细胞、胆汁代谢或合成功能线索 | 轻度升高不等于严重肝病，也不等于可以自行买护肝产品 | 记录饮酒、脂肪肝、药物、保健品、感染和既往肝病；按医生建议复查 |
| 血常规 | 红细胞、白细胞、血小板、血红蛋白等血液细胞线索 | 不要把白细胞高低、血红蛋白低或血小板异常单独解释成某个病 | 结合发热、感染、出血、乏力、贫血症状、用药和既往结果问医生 |
| 尿常规 | 尿蛋白、潜血、尿糖、酮体、细胞和感染线索 | 一次异常可能受取样、经期、运动、感染影响，但反复异常不能忽视 | 规范留尿复查；有血尿、蛋白尿、糖尿病、高血压或肾病风险时问医生 |
| 甲状腺 | TSH、T3/T4 等提示甲状腺功能线索 | 不要只凭一个数值自行吃药或停药 | 有心悸、怕冷怕热、体重变化、乏力、备孕孕产或已用药时，按医生建议复查 |
| 肿瘤标志物 | 多数用于已诊断癌症后的分期、疗效、复发监测，少数用于高风险或症状场景 | 不要把“全套肿瘤标志物”当成普通人癌症筛查，也不要把阴性当成排除癌症 | 优先按年龄和风险做被指南认可的筛查；异常结果让医生判断是否需要影像、内镜或病理 |
| 影像提示结节/囊肿 | 影像发现需要结合部位、大小、形态和既往变化 | 不要把“结节”直接等同于癌，也不要因为没症状就完全不管 | 找旧片对比；按报告建议或专科医生意见决定复查时间和下一步 |

## 四高和肾功能要合起来看

血压、血脂、血糖、尿酸、体重腰围和肾功能，最好不要拆开看。

| 组合 | 重点不是 |
|---|---|
| 血压高 + 血脂异常 | 只问少盐或少油，而是问心梗、卒中、肾损伤风险怎么整体管理 |
| 血糖边缘 + 腰围增加 + 甘油三酯高 | 只问是不是糖尿病，而是问胰岛素抵抗和内脏脂肪风险 |
| 尿酸高 + 血压高 + 肾功能边缘 | 只问海鲜能不能吃，而是问肾脏排泄、饮酒、甜饮料、体重和用药 |
| 糖尿病 + 血压/血脂异常 | 只盯血糖，而是同时防心脑血管、肾脏、眼底、神经和足部并发症 |

如果这些组合反复出现，把结果转进 [慢病指标记录表](../templates/chronic-marker-log.md)，下次复诊直接带给医生。

## 复查前问医生的 6 句话

1. 这个异常更像单次波动，还是需要确认的趋势？
2. 需要多久复查？复查前要不要空腹、停某些保健品或避免剧烈运动？
3. 这个指标要和哪些指标一起看？
4. 有没有必要进一步做影像、内镜、尿检、家庭血压或专科检查？
5. 我现在需要先改变生活方式，还是已经需要药物或专科判断？
6. 什么症状或数值变化出现时，要提前就医？

## 特别容易误会的三件事

**第一，参考范围不是疾病边界。**  
参考范围帮助解释结果，但不同实验室、年龄、性别、孕产状态、用药和检测方法都可能影响结果。

**第二，筛查阳性不是诊断。**  
筛查或体检发现异常，通常意味着需要复查或进一步检查。很多疾病最终需要医生结合症状、影像、病理或其他检查判断。

**第三，正常报告不能解释危险症状。**  
近期体检正常，不代表胸痛、卒中样症状、严重气短、晕厥、异常出血或意识改变可以继续观察。
