# 就医前问题清单

> 本页不是医疗建议。出现胸痛胸闷、卒中样症状、严重呼吸困难、意识改变、无法控制出血、严重疼痛、自伤风险等危险信号时，先急救或急诊，不要为了整理清单而延误就医。

门诊前不用写长材料。把下面这些短表填到手机备忘录里，就够用了。

## 30 秒开场

| 先说什么 | 填一句话就行 |
| --- | --- |
| 我这次主要想看 | 例如胸闷、腹痛、复查报告、调整用药 |
| 从什么时候开始 | 今天、三天前、两周前，还是反复很多次 |
| 最近有没有变化 | 加重、变频繁、范围变大、出现新症状 |
| 最影响什么 | 睡觉、吃饭、走路、工作、上学、照护 |
| 我带了什么资料 | 报告、影像、用药清单、家庭记录 |
| 最想问医生 | 下一步做什么，什么情况要提前回来 |

## 就医前带什么

| 带什么 | 重点 |
| --- | --- |
| 最近报告 | 化验、影像、病理、出院小结，优先带异常和最新的 |
| 用药和过敏 | 处方药、非处方药、保健品、草药、漏服停药、过敏史 |
| 关键趋势 | 血压、血糖、血脂、尿酸、肾功能、体重腰围，带最近 1-3 次 |
| 既往背景 | 重大疾病、手术、急诊、住院、家族史 |
| 近期变化 | 感染、受伤、怀孕/产后、旅行、压力、饮酒、剧烈运动 |

如果准备拔牙、种牙、内镜、小手术或其他有创操作，要主动说明基础病和影响凝血、免疫、骨代谢或肿瘤治疗相关的用药。不要自行停药。

## 离开诊室前确认

| 问清什么 | 可以这样问 |
| --- | --- |
| 当前判断 | 现在最需要排除什么？还有哪些不确定？ |
| 下一步 | 接下来是检查、用药、观察、复查，还是转诊？ |
| 回家边界 | 什么情况算正常恢复？什么情况要提前回来或急诊？ |
| 复查安排 | 多久复查？复查前要注意什么？需要带哪些资料？ |

## 陪诊人只做三件事

| 做什么 | 注意 |
| --- | --- |
| 补资料 | 患者能自己说时，优先让本人说 |
| 记下一步 | 记录检查、用药、复查和危险边界 |
| 回家转动作 | 谁买药、谁预约、谁记录、谁提醒 |

陪诊不是替患者做决定，而是帮助真实信息不掉在诊室外。
